# توثيق صفحة الفوترة الوطنية (National Billing Screen)

## نظرة عامة
صفحة الفوترة الوطنية هي شاشة مخصصة لإرسال الشحنات المكتملة إلى نظام الفوترة الوطني الأردني. تتيح للمستخدم عرض الشحنات التي تم توصيلها وإرسالها كفواتير رسمية للنظام الضريبي.

---


## 🎯 الوظيفة الأساسية

### الهدف من الصفحة
1. عرض جميع الشحنات التي تم توصيلها (`status = 'تم توصيلها'`)
2. فلترة الشحنات التي لم يتم إرسالها للفوترة بعد (`isSentToFaotara != true`)
3. السماح باختيار شحنات متعددة وإرسالها كفاتورة واحدة
4. التواصل مع نظام الفوترة الوطني الأردني

```dart
Future<Map<String, dynamic>> loginUser(Map<String, dynamic> data) async {
  dynamic response;
  
  // استدعاء API عبر Proxy (للويب)
  response = await _callProxy(
    method: 'POST',
    url: '$API_URL/users/auth/login',
    body: data,
    headers: {'Content-Type': 'application/json'},
  );
  
  // حفظ التوكن مع وقت الانتهاء
  final int expiresIn = int.tryParse(response['expires_in'].toString()) ?? 0;
  final expiryTime = DateTime.now().millisecondsSinceEpoch + expiresIn;
  await UserPreferences.saveToken(response['access_token'], expiryTime);
  
  return {
    'token': response['access_token'],
    'refreshToken': response['refresh_token'],
    'role': response['role'],
  };
}
```

```dart
Future<Map<String, String>> _getAuthHeaders({String? activity}) async {
  final token = await getToken();
  final effectiveActivity = activity ?? await UserPreferences.getActivity();
  
  final headers = {
    'Content-Type': 'application/json',
    if (token != null) 'Authorization': 'Bearer $token',
    if (_languageCode != null) 'Accept-Language': _languageCode!,
    if (effectiveActivity != null && effectiveActivity.isNotEmpty)

  };
  
  return headers;
}
```

## 🌐 نظام Proxy (للويب)

### لماذا Proxy؟
بسبب قيود CORS في المتصفحات، يتم استخدام Cloud Function كـ Proxy.

### الدالة
```dart
Future<dynamic> _callProxy({
  required String method,
  required String url,
  dynamic body,
  Map<String, String>? headers,
}) async {
  final HttpsCallable callable =
      FirebaseFunctions.instance.httpsCallable('proxyRequest');
      
  final response = await callable.call({
    'method': method,
    'url': url,
    'body': body,
    'headers': headers,
  });
  
  final String resultString = response.data;
  final Map<String, dynamic> result = json.decode(resultString);
  
  final int statusCode = result['status'] ?? 200;
  final dynamic responseData = result['data'];
  
  if (statusCode >= 200 && statusCode < 300) {
    return responseData;
  } else {
    throw HttpException('API Error: $statusCode');
  }
}
```

### Cloud Function (proxyRequest)
```javascript
// Firebase Cloud Function
exports.proxyRequest = functions.https.onCall(async (data, context) => {
  const { method, url, body, headers } = data;
  
  const response = await fetch(url, {
    method: method,
    headers: headers,
    body: body ? JSON.stringify(body) : undefined
  });
  
  const responseData = await response.json();
  
  return JSON.stringify({
    status: response.status,
    data: responseData
  });
});
```

### السيناريو: إرسال 3 شحنات للفوترة

1. **المستخدم يفتح الصفحة**
   - يتم جلب الشحنات من Firebase
   - الفلتر: `status = 'تم توصيلها'` و `isSentToFaotara != true`

2. **المستخدم يختار الشحنات**
   - يضغط على Checkbox لكل شحنة
   - أو يضغط على "اختيار الكل"
   - العدد المختار: 3

3. **المستخدم يضغط "ارسال المحدد لفوتره (3)"**
   - يظهر مربع تأكيد
   - المستخدم يؤكد

4. **النظام يبدأ الإرسال**
   - يظهر مؤشر التحميل
   - يحصل على رقم الفاتورة التالي من API
   - يحصل على معلومات النشاط من SharedPreferences

5. **بناء بيانات الفاتورة**
   - لكل شحنة:
     - سعر التوصيل: 5.000 JOD
     - الضريبة: 0.800 JOD
     - الإجمالي: 5.800 JOD
   
   - الإجمالي الكلي:
     - المجموع الفرعي: 15.000 JOD
     - الضريبة الكلية: 2.400 JOD
     - المبلغ الإجمالي: 17.400 JOD

6. **إرسال الفاتورة**
   - POST إلى `/sme/invoices/`
   - الاستجابة: رقم الفاتورة + UUID

7. **تحديث Firebase**
   - Batch Update لـ 3 مستندات
   - `isSentToFaotara = true`

   - إخفاء مؤشر التحميل
   - إظهار رسالة نجاح
